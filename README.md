# 此项目使用CPP制作而成，利用CPP的特性与其执行速度，为日常提供方便之取。

## 环境：Windows

## 简介
### 该项目为存档工具，目的为解决在日常中记不住JM等网站作者与作品的不便，即我看了哪个作品？我保存了哪个作品？
### 该工具以命令行的形式提供对车牌号的保存、提取两大类功能。

## 使用（温馨提示：你需要一定的cmd前置知识）
### 当你下载该工具（AnimeArchive.exe）到本地之后，你需要学会该工具的内部命令，这有一定的学习成本。
### （以下1-3操作皆需要cmd定位到存有AnimeArchive.exe的文件目录下。）
### 1.通过-h命令获取内部帮助：并右键打开cmd，输入：./AnimeArchive.exe -h并按下回车键，即可获取内部帮助。
### 注意：该工具的第一个命令参数需为非目标文件即-h。
### 2.通过-a保存车牌号：首先确认要保存的文件的路径，随后将路径作为第一个参数，比如C盘下的AFiles.txt，./AnimeArchive.exe "C:\\AFiles.txt" ，这时候不要按下回车键，再随后输入-a命令保存车牌号，./AnimeArchive.exe "C:\\AFiles.txt" -a 350234，并按下回车键，将显示是否添加成功
### 3.若添加成功之后，可通过-t与-o完成组合命令，按照指定内容寻找车座：./AnimeArchive.exe "C:\\AFiles.txt" -t 350234 -o jm，并按下回车键，工具会自动送你上车。（注意：这里的-t是提取，然而提取的是预先保存的车牌号）
