# 此项目使用CPP制作而成，利用CPP的特性与其执行速度，为日常提供方便之取。

## 简介
### 该项目为存档工具，目的为解决在日常中记不住JM等网站作者与作品的不便，即我看了哪个作品？我保存了哪个作品？
### 该工具以命令行的形式提供对车牌号的保存、提取两大类功能。

## 使用（温馨提示：你需要一定的cmd前置知识）
